Hybrid Starlight

Local Tauri tray + Pipecat voice pipeline + provider lanes + browser-use + Codex/Claude execution.

  • Best control over latency, privacy, and tools.
  • Lets ElevenLabs or OpenAI be swappable provider lanes.

OpenAI Realtime

  • Best if speech-to-speech and tool calling should share one provider surface.
